# StyleSync — Smart Virtual Trial Room

A responsive, browser-based prototype of a digital wardrobe and smart fitting mirror.

## Quick start on Windows

1. Extract this ZIP into your project folder.
2. Double-click **`Start-StyleSync.bat`**.
3. The app opens at **http://127.0.0.1:8000**.
4. Keep the terminal window open while using the app. Press `Ctrl+C` in that window to stop the server.
5. Connect your wired USB webcam before starting the demo. Select **Start camera** and allow camera access when the browser asks.
6. If the browser opens the integrated camera instead, use the camera/site-permissions control beside the address bar (or the browser camera settings) to select the USB webcam, then refresh the page and start the camera again.

If the batch file cannot find Python, open PowerShell in this folder and run:

```powershell
py -m http.server 8000
```

Then browse to `http://127.0.0.1:8000/`.

Camera access is restricted by browsers to secure contexts. `localhost` and `127.0.0.1` are allowed for local development; opening `index.html` directly as a `file://` URL may not allow camera access.

## Included functionality

- Filter the collection by All, Shirts, Polos, Tees, and Hoodies.
- Search products by name, type, fit, material, or category. Press `/` to focus search and `Esc` to clear it.
- Select a product to update the mirror, detailed product story, material/texture notes, construction features, fit guidance, care notes, price, and styling recommendation.
- Explore enhanced vector garment artwork with more visible fabric textures, stitching, collars, pockets, plackets, cuffs, and hoodie details.
- Choose a preview size (XS–XXL) to adjust the on-screen overlay scale. This is not a body measurement, fit recommendation, or live-stock check.
- Start and stop the live camera preview with clear permission and device error messages.
- Load MediaPipe Pose Landmarker on first camera use and track the visible shoulder line in real time.
- Anchor and smoothly reposition the selected garment overlay as the user moves; show pose landmarks as tracking feedback.
- Mirror or un-mirror the camera feed.
- Show or hide the selected garment overlay.
- Adjust the garment overlay width and vertical position manually.
- Reset the complete preview to its initial state.
- Save a PNG snapshot of the mirror stage, including the live camera frame when active and the garment overlay when visible.
- Navigate to the wardrobe, product details, how-it-works, and about sections.
- Responsive layouts for desktop, tablet, and mobile screens.

## Catalogue content note

Product materials, descriptions, size options, prices, and care instructions are illustrative demo content created to make the prototype feel like a retail catalogue. Replace them with verified supplier information before using StyleSync for real sales or stock decisions. The preview-size selector adjusts only the on-screen garment scale; it is not connected to inventory or body measurements.

## Camera and AI setup

The camera requires `localhost` or HTTPS. On the first camera start, the browser loads the MediaPipe Tasks Vision JavaScript bundle, its WebAssembly runtime, and the Pose Landmarker Lite model from their published CDNs. Keep an internet connection available for the first load. If the model cannot load, the app switches back to the manual overlay rather than blocking the camera. After loading, pose inference runs in the browser on the camera stream; the app does not upload camera frames to a StyleSync backend.

The detector uses the shoulder landmarks to estimate the garment's center, width, and tilt. It is a visual prototype: it does not perform photorealistic cloth simulation, body segmentation, exact body measurements, or reliable size prediction. Camera framing, lighting, loose clothing, and partial visibility can affect tracking. Manual size and vertical adjustment controls remain available as fallbacks. The style notes are curated demo content, not generated by a connected AI service.

Pose detection runs on the browser's main thread at a reduced frame rate to keep this lightweight demo responsive. A production build should move inference to a worker and validate fit with calibrated measurements and real garment data.
