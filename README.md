# StyleSync — Smart Virtual Trial Room

A responsive, browser-based prototype of a digital wardrobe and smart fitting mirror.

## Quick start on Windows

1. Extract this ZIP into your project folder.
2. Double-click **`Start-StyleSync.bat`**.
3. The app opens at **http://127.0.0.1:8000**.
4. Keep the terminal window open while using the app. Press `Ctrl+C` in that window to stop the server.
5. Select **Start camera** and allow camera access when the browser asks.

If the batch file cannot find Python, open PowerShell in this folder and run:

```powershell
py -m http.server 8000
```

Then browse to `http://127.0.0.1:8000/`.

Camera access is restricted by browsers to secure contexts. `localhost` and `127.0.0.1` are allowed for local development; opening `index.html` directly as a `file://` URL may not allow camera access.

## Included functionality

- Filter the collection by All, Shirts, Polos, Tees, and Hoodies.
- Search products by name, type, fit, material, or category. Press `/` to focus search and `Esc` to clear it.
- Select a product to update the garment preview, product details, price, and style note.
- Start and stop the live camera preview with clear permission and device error messages.
- Mirror or un-mirror the camera feed.
- Show or hide the selected garment overlay.
- Adjust the garment overlay width and vertical position manually.
- Reset the complete preview to its initial state.
- Save a PNG snapshot of the mirror stage, including the live camera frame when active and the garment overlay when visible.
- Navigate to the wardrobe, how-it-works, and about sections.
- Responsive layouts for desktop, tablet, and mobile screens.

## Prototype scope and limitations

This build uses a manually positioned garment illustration over the camera feed. It does **not** include pose estimation, body segmentation, automatic garment warping, body measurements, or AI size prediction. The style notes are curated demo content and are not generated by a connected AI service. The snapshot combines the camera frame and selected overlay; it is not a photorealistic try-on render.

The project is intentionally dependency-free at runtime: no package installation, external icon library, or remote font stylesheet is required.
